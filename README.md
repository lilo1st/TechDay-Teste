# TechDay 2025 — Nexora Tech

## 🇧🇷 Português (PT-BR)

**O futuro da tecnologia começa aqui.**

O TechDay 2025 é um hotsite desenvolvido para apresentar e divulgar um evento fictício voltado à tecnologia, inovação e transformação digital no Brasil. Organizado pela Nexora Tech, o evento reúne desenvolvedores, empreendedores, estudantes, pesquisadores, designers e profissionais da área tecnológica em um ambiente voltado ao aprendizado, networking e compartilhamento de conhecimentos.

O site apresenta informações sobre o evento, incluindo sua organização, público-alvo, localização, programação, palestras, workshops e objetivos. Também conta com seções de divulgação, chamadas para inscrição, canais de contato e uma interface de assistente virtual chamada NexBot, criada para orientar os visitantes e apresentar informações relevantes sobre o evento.

### Tecnologias utilizadas

- **HTML5:** Utilizado na construção e estruturação de todo o site, organização do conteúdo e desenvolvimento das seções da página.

### Funcionalidades e seções

- Apresentação e divulgação do evento TechDay 2025.
- Informações sobre a empresa organizadora, Nexora Tech.
- Apresentação dos diferentes públicos-alvo do evento.
- Informações sobre localização, endereço e acesso ao local.
- Programação completa com horários e atividades.
- Divulgação de palestras, workshops e networking.
- Seção institucional sobre os objetivos do evento.
- Links para canais de contato e informações adicionais.
- Interface de assistente virtual (NexBot) para orientação dos visitantes.

### Objetivo do projeto

O TechDay 2025 foi desenvolvido como um projeto de hotsite para aplicar conhecimentos de desenvolvimento Front-End para Web, utilizando HTML na estruturação e organização de uma página informativa. O projeto busca apresentar um evento tecnológico de maneira clara, organizada e acessível, proporcionando aos visitantes uma experiência de navegação intuitiva.

### Contexto do desenvolvimento

O TechDay 2025 foi desenvolvido experimentalmente como uma atividade prática de sala de aula, com o objetivo de explorar e aplicar conceitos de estruturação de páginas web utilizando HTML5.

## 🇺🇸 English (EN-US)

**The future of technology starts here.**

TechDay 2025 is a website developed to showcase and promote a fictional event focused on technology, innovation, and digital transformation in Brazil. Organized by Nexora Tech, the event brings together developers, entrepreneurs, students, researchers, designers, and technology professionals in an environment dedicated to learning, networking, and knowledge sharing.

The website provides information about the event, including its organization, target audience, location, schedule, talks, workshops, and objectives. It also features promotional sections, registration calls to action, contact channels, and a virtual assistant interface called NexBot, designed to guide visitors and provide relevant event information.

### Technologies Used

- **HTML5:** Used to build and structure the entire website, organize its content, and develop the page sections.

### Features and Sections

- TechDay 2025 event presentation and promotion.
- Information about the organizing company, Nexora Tech.
- Presentation of the event's different target audiences.
- Location, address, and venue accessibility information.
- Complete event schedule with times and activities.
- Talks, workshops, and networking promotion.
- Institutional section explaining the event's objectives.
- Links to contact channels and additional information.
- Virtual assistant interface (NexBot) to guide visitors.

### Project Objective

TechDay 2025 was developed as an event landing page project to apply Front-End Web Development concepts, using HTML to structure and organize an informative website. The project aims to present a technology event in a clear, organized, and accessible way, providing visitors with an intuitive browsing experience.

### Development Context

TechDay 2025 was experimentally developed as a classroom activity, with the purpose of exploring and applying web page structuring concepts using HTML5.
